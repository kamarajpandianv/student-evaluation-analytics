# Student Evaluation Analytics System

A Python-based academic analytics system developed using NumPy and Matplotlib for student performance evaluation and visualization.

## Features

- CSV Processing
- Data Cleaning
- Attendance Analytics
- Pass/Fail Analytics
- Ranking System
- Grade System
- CSV Report Generation
- Data Visualization

## Technologies Used

- Python
- NumPy
- Matplotlib
- CSV
